Present system

Simple → routine / state
Continuous → temporary / happening now
Perfect → result up to now
Perfect Continuous → duration / ongoing process

Narrative grammar

Past Simple → main completed event
Past Continuous → background / action in progress
Past Perfect → earlier past event

Passive: be + V3 · Articles: a/an → first mention, the → specific/known, zero → general idea.
